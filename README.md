# 모바일 프로그래밍

동양미래대학교 2026년 1학기 모바일 프로그래밍 수업의 실습·과제 아카이브입니다.

## 🛠 Skills & Tools
* **Language**: Java
* **IDE**: Android Studio (Hedgehog 버전 사용)
* **Database**: SQLite
* **Target API**: Android 14.0 (U)

## 📚 교재 및 참고 자료
* **메인 교재**: Android Studio를 활용한 안드로이드 프로그래밍 9판 (우재남, 박길식 저 / 한빛아카데미)
* **사전 학습 자료**: [안드로이드에 필요한 Java 문법 기초 강의 (YouTube)](https://youtube.com/playlist?list=PLV6EMqotxTnH6qcKPAimUcule7kaT10vv&si=difwxknTE8tmN1IL)
* **예제 소스 코드**: [한빛아카데미 자료실](https://www.hanbit.co.kr/support/supplement_survey.html?pcode=B9584532323)
